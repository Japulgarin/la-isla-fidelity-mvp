# La Isla Fidelity MVP

Static, Spanish-first NFC loyalty-card demo for La Isla Club.

## NFC URL

Program the NFC tag with the deployed URL followed by `?tap=1`. Each tap increments the anonymous loyalty card stored in that browser until it reaches five visits.

## Privacy

This demo stores no customer identity or server-side data. An anonymous fidelity number and visit progress live in a first-party cookie on the visitor's device for one year and can be reset from the interface.
